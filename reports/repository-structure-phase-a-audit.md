## Current structure assessment

**一部整理済み・移行途中**.

The public build has a recoverable source-to-output boundary for the active routes, but HTML, CSS, JS, and images are still split between root and `src/`, while `src/public/` preserves a second legacy asset tree. The current state is not fully consolidated and should not be treated as such.

## Safe migration proposal

1. Keep this mapping as the baseline and add a machine-readable source map only after reviewing this document.
2. Complete a separate reference inventory for every C candidate, including historical/rollback value and active runtime evidence.
3. Choose one pilot family, preferably shared CSS, and generate a parallel output without deleting the existing root source.
4. Compare source/build output, SEO, links, runtime, and Visual Regression for the pilot.
5. Migrate JS and then HTML page families only after the pilot is proven and rollback is available.
6. Update Webpack and generated consistency checks together; rebuild `docs/` from source.
7. Run local checks and the existing GitHub Actions/browser verification at every migration gate.
8. Request explicit approval before any legacy deletion, relocation, or broad asset deduplication.
