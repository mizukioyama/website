## `src/public/` detailed findings

The directory contains 197 tracked files. Repository-wide active configuration and test searches found no build copy pattern, runtime import/fetch, HTML reference, CI mapping, or Playwright mapping that points to `src/public/`. The one active reference is a deliberate negative check in `scripts/check-seo.cjs` for `src/public/robots.txt` so a Project Site path is not reintroduced.

The tree is internally self-contained as a historical static site: its fragments link to sibling pages, its CSS points to `src/public/img`, and its legacy `page-nation.js` creates image/modal markup from its own image records. Those internal references do not make it part of the current build. The current Gallery uses root `js/page-nation.js` and root `img/` through the explicit Webpack copy list.

Comparison results:

- CSS: 9 overlapping names; `noise.css` is byte-identical, while `all.css`, `footer.css`, `form.css`, `gallery.css`, `index.css`, `menu.css`, `mobile.css`, and `modal.css` differ.
- JS: 16 overlapping names; vendor files such as `jquery.ripples-min.js`, `loading.js`, `mobile.js`, `p5.min.js`, `three.r134.min.js`, `time.js`, `vanta.fog.min.js`, and `vanta.trunk.min.js` are identical, while active behavior files such as `bg_wave.js`, `cursor.js`, `form.js`, `menu.js`, `page-nation.js`, `side.js`, and `security.js` differ.
- Images: 160 overlapping files are byte-identical; `src/public/img/web.ico` is the only public-only file found, and no root-only image was found in the overlap comparison.

Do not deduplicate or delete the artwork tree in this phase. Any future removal requires a rights/reference/rollback review and explicit approval.
